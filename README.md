# Kikirara

A personal money app for Malaysia: bills and commitments (mortgage, credit cards, utilities, PTPTN, subscriptions), daily spending, an insurance summary with coverage gaps and tax relief, and vehicles (service, fuel, car loan, road tax, licence).

## Publish with GitHub Pages
Upload every file in this folder to the repository root, then go to Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Your data
Each person's data is saved on their own phone and never shared. To keep it safe:
- **Add to Home Screen** (Safari: Share → Add to Home Screen; Chrome: ⋮ → Install app). Installed apps aren't auto-cleared.
- **Back up regularly** from the Home screen. The backup is one `.json` file you can save to iCloud Drive, Google Drive or WhatsApp, and restore on any phone.

## Updating the app
After uploading a new `index.html`, change `VERSION` in `sw.js` (e.g. `kikirara-v2`) so phones pick up the new version.
